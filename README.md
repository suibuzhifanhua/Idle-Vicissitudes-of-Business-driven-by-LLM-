# 商海浮沉 — 使用说明

> LLM 驱动的放置式经营模拟游戏。在虚构的商业都市里，从一无所有到商业帝国，每一步都由你决策。

## About

A browser-based idle business simulation game powered by local LLM (Ollama). Start from nothing — choose your origin, build businesses across cities, manage employees, negotiate with NPCs, trade stocks, and climb your way to a commercial empire. Every decision matters, and the LLM generates dynamic narratives for key events.

**Tech Stack:** Vanilla JS + Ollama API + Web Audio  
**Play:** Open `index.html` in browser, start Ollama, and dive in.

## 快速开始

### 方式一：通过 .bat 文件启动（推荐）

双击桌面上的 **`启动游戏.bat`**，游戏将自动在浏览器中打开。

### 方式二：手动启动本地服务器

> ⚠️ **必须通过 HTTP 服务器打开**，直接双击 `index.html` 会导致 LLM 功能因浏览器安全限制而无法使用。

```bash
# 在游戏目录打开终端，运行：
python -m http.server 8765

# 然后在浏览器中访问：
http://localhost:8765
```

### 关闭游戏

双击 **`关闭游戏.bat`**，或在游戏内点击顶栏的 **🚪 退出游戏** 按钮。

## LLM 配置（核心功能）

游戏深度集成本地 LLM，用于生成**事件叙事、NPC 对话、员工背景故事、决策描述**等内容。没有 LLM 时游戏仍可正常进行，但叙事体验会大幅减弱。

### 默认配置

| 参数 | 默认值 |
|------|--------|
| LLM 接口地址 | `http://localhost:11434`（Ollama） |
| 模型 | `qwen3.5:4b` |
| Temperature | 0.7 |
| 最大 Token | 300 |

### 配置步骤

1. 确保已安装并运行 [Ollama](https://ollama.com/)
2. 拉取推荐模型：`ollama pull qwen3.5:4b`
3. 游戏内点击顶栏 **⚙ 设置** → 修改接口地址和模型名称
4. 顶栏左侧绿色圆点亮起表示 LLM 已连接

### LLM 功能开关

在设置面板中可以分别开启/关闭：
- **事件叙事**：随机事件的 AI 描述
- **员工背景**：招聘时生成员工故事
- **NPC 对话**：人脉 NPC 的 AI 台词
- **决策叙事**：重大决策的背景描述
- **氛围生成**：场景氛围文字

## 核心玩法

### 放置机制

游戏每 **15 秒**执行一次 Tick（游戏内约 1 小时），自动结算：
- 所有业务的收益与成本
- 员工薪资扣除
- 压力自然衰减
- 忠诚度与声誉衰减

### 时间系统

游戏内 24 个 Tick = 1 个游戏日，并有昼夜循环，影响界面风格：

| 时段 | 游戏时间 |
|------|----------|
| 黎明 | 05:00 |
| 白天 | 07:00 |
| 黄昏 | 17:00 |
| 夜晚 | 19:00 |

### 天气系统

天气随机变化，影响收益和事件概率：

| 天气 | 收益影响 | 事件倾向 |
|------|----------|----------|
| 晴天 | ×1.0 | 中性 |
| 雨天 | ×0.95 | 负面概率↑ |
| 暴风雨 | ×0.85 | 危机概率↑↑ |
| 高温 | ×0.92 | 负面概率↑ |
| 雪天 | ×0.88 | 中性 |
| 大雾 | ×0.90 | 中性 |

### 玩家属性

| 属性 | 说明 |
|------|------|
| 💰 资产 | 当前现金，低于 -50万 连续5个Tick将触发破产 |
| ⭐ 声誉 | 0-100，影响区域解锁和 NPC 关系 |
| 😰 压力 | 0-100，过高影响决策质量，积累触发负面事件 |
| 🤝 人脉 | 社会关系网络值，影响合作机会 |

### 手动工作

点击中央区域的**手动拉项目**按钮（或按 `空格`）可立即获得一次性收益，但有 **20 Tick 冷却时间**，且有 8% 概率触发负面结果。

### 幕次系统

游戏共有 5 幕，随资产和声誉增长自动推进：

| 幕次 | 里程碑 | 解锁内容 |
|------|--------|----------|
| 第一幕 | 创业起步 | 新海市基础区域 |
| 第二幕 | 区域扩张 | 更多业务类型、京都市 |
| 第三幕 | 城市布局 | 媒体矩阵、深港市 |
| 第四幕 | 全国扩张 | 国际城市（新加坡、东京） |
| 第五幕 | 全球版图 | 纽约、伦敦、迪拜 |

## 业务系统

### 业务类型

| 业务 | 图标 | 区域 | 解锁条件 | 特点 |
|------|------|------|----------|------|
| 便利连锁 | 🏪 | 永宁区 | 初始 | 稳定现金流，低风险 |
| 餐饮连锁 | 🍽️ | 永宁/锦绣 | 50万 | 每级增加1个员工槽 |
| 科技工作室 | 💻 | 星海区 | 150万+第1幕 | 高收益，需研发点 |
| 写字楼租赁 | 🏢 | 金湾区 | 300万+第2幕 | 被动收入，稳定 |
| 量化基金 | 📈 | 金湾区 | 1000万+第2幕 | 超高收益，高风险 |
| 新能源开发 | ⚡ | 铁西/星海 | 800万+第3幕 | 3级以上有政府补贴 |
| 媒体矩阵 | 📺 | 锦绣区 | 3000万+第3幕 | 高收益，声誉加速 |

### 升级系统

每个业务有 **5 个等级**，升级需要消耗资金（单位：万元/Tick 的运营成本形式体现），各级收益大幅提升。

升级要求：
1. 业务所在区域必须已解锁
2. 资金充足
3. 达到对应幕次要求

### 业务协同

同一区域或类型的多条业务线可产生**协同加成**，中央区域顶部会显示当前协同状态。

| 📋 管理者 | 2.0 | 业务 +30%，忠诚衰减 -50% | 员工数≥5 |

### 员工管理注意事项

- 员工有**忠诚度**，随时间自然衰减，需主动维护
- 忠诚度过低的员工可能**主动离职**
- 长期加班会触发**Burnout**事件
- 解雇员工需支付赔偿

## 存档说明

- 游戏每 **10 Tick** 自动保存一次
- 存档保存在**浏览器 localStorage** 中，清除浏览器数据会丢失存档
- 支持**多槽位存档**，可在设置中管理
- 支持**离线收益**：关闭游戏后重新打开，系统会计算最多 **12小时** 的离线收益

> ⚠️ 重要提醒：不要在隐私/无痕模式下游玩，否则关闭浏览器后存档会丢失。

解锁成就时右上角会弹出**成就横幅通知**，点击 🏆 成就按钮可查看所有进度。

## 常见问题

**Q：LLM 离线了，游戏还能玩吗？**  
A：可以正常游玩所有核心功能，只是事件叙事、NPC对话等文字内容会使用预设模板代替。

**Q：游戏卡顿了怎么办？**  
A：减少同时运行的业务数量，或关闭天气视觉效果（设置中）。

**Q：为什么资产一直减少？**  
A：检查员工总薪资和业务运营成本是否超过了收益。临时解雇部分员工或暂停高成本业务。

**Q：如何触发 LLM 生成的特殊事件？**  
A：保持 LLM 在线状态，随机事件触发时（约每6个Tick检查一次，基础概率30%）会调用 LLM 生成叙事。

**Q：存档在哪里，如何备份？**  
A：存档在浏览器 localStorage，key 为 `shanghaifc_settings` 和游戏状态。可在浏览器开发者工具中导出，或等待后续版本的存档导出功能。

**Q：游戏时间和现实时间的关系？**  
A：每15秒现实时间 = 游戏内约1小时；每24个Tick = 1个游戏日。
