# 商海浮沉 — 使用说明

> LLM 驱动的放置式经营模拟游戏。在虚构的商业都市里，从一无所有到商业帝国，每一步都由你决策。

## About

A browser-based idle business simulation game powered by local LLM (Ollama). Start from nothing — choose your origin, build businesses across cities, manage employees, negotiate with NPCs, trade stocks, acquire real-world assets, auction collectibles, and climb your way to a commercial empire. Every decision matters, and the LLM generates dynamic narratives, business news, competitor intelligence, and market sentiment analysis.

**Tech Stack:** Vanilla JS + Ollama API + Python (local server)
**Codebase:** core.js 3,500+ lines (149 functions) · ui.js 2,100+ lines (86 functions) · llm.js 416 lines (33 functions)
**Play:** 运行 `启动游戏.bat` 或 `python server.py`，浏览器访问 `http://localhost:8765`

## 快速开始

### 方式一：通过 .bat 文件启动（推荐）

双击 **`启动游戏.bat`**，游戏将自动在浏览器中打开。

### 方式二：手动启动本地服务器

> ⚠️ **必须通过 HTTP 服务器打开**，直接双击 `index.html` 会导致 LLM 功能因浏览器安全限制而无法使用。

```bash
# 在游戏目录打开终端，运行：
python server.py

# 然后在浏览器中访问：
http://localhost:8765
```

### 关闭游戏

双击 **`关闭游戏.bat`**，或在游戏内点击顶栏的 **🚪 退出游戏** 按钮。

## LLM 配置

游戏深度集成本地 LLM，用于生成**事件叙事、NPC 对话、员工背景故事、商业新闻、竞争对手情报、市场情绪分析、动态事件、里程碑叙事**等内容。没有 LLM 时游戏仍可正常进行，但叙事体验会大幅减弱。

### 默认配置

| 参数 | 默认值 |
|------|--------|
| LLM 接口地址 | `http://localhost:11434`（Ollama） |
| 模型 | `qwen3.5:4b` |
| Temperature | 0.7 |
| 最大 Token | 300 |

### 配置步骤

1. 确保已安装并运行 [Ollama](https://ollama.com/)
2. 拉取推荐模型：`ollama pull qwen3.5:4b`
3. 游戏内点击顶栏 **⚙ 设置** → 修改接口地址和模型名称
4. 顶栏左侧绿色圆点亮起表示 LLM 已连接

### LLM 功能开关

在设置面板中可以分别开启/关闭：
- **事件叙事**：随机事件的 AI 描述
- **员工背景**：招聘时生成员工故事
- **NPC 对话**：人脉 NPC 的 AI 台词
- **决策叙事**：重大决策的背景描述（新增）

### LLM 请求队列

内置请求队列管理，最大并发 **2** 个请求，自动降级和冷却机制，防止 Ollama 过载。

## LLM 增强功能

以下功能在 LLM 在线时自动激活，无需手动配置：

### 📰 商业新闻（每 20 Tick）
LLM 根据当前市场状态、玩家业务和竞争对手动态，自动生成商业快讯。在右侧事件日志区顶部以青色标签展示。

### 🔍 竞争对手情报（每 30 Tick）
LLM 分析竞争对手排名和市场份额变化，生成竞争情报简报。以紫色标签展示在事件日志区。

### 📊 市场情绪引擎（每 15 Tick）
LLM 综合分析游戏全局状态（资金、声望、业务、经济周期等），输出 **0-100 市场情绪指数**。仪表盘新增市场情绪卡片实时展示，情绪值影响股价波动幅度、事件触发概率和资产市场价格。

| 情绪区间 | 图标 | 标签 |
|---------|------|------|
| 80-100 | 🔥 | 极度乐观 |
| 65-79 | ☀️ | 偏乐观 |
| 45-64 | ☁️ | 中性 |
| 25-44 | 🌧️ | 偏悲观 |
| 0-24 | ❄️ | 极度悲观 |

### ⚡ AI 动态事件（每 25 Tick，30% 概率）
LLM 完全自主生成事件标题、描述和选项，不再依赖预定义事件表。极端市场情绪下触发概率提升至 50%。AI 事件效果由解析引擎自动映射为资金/声誉/压力数值。

### 🎯 决策叙事
决策事件卡片中新增金色斜体叙事框，LLM 为每次重大决策生成背景铺垫文字。

### 📜 里程碑叙事
达成资产里程碑或高级成就时，LLM 生成个性化叙事文字，取代固定文本。

### 🔗 叙事连续性
系统维护最近事件叙事摘要链，新事件叙事会参考之前的上下文，形成因果连贯感。

### 🧠 NPC 对话上下文注入
NPC 对话 prompt 自动注入最近游戏事件摘要，NPC 会评论玩家最近的商业举动，大幅提升对话沉浸感。

## 核心玩法

### 放置机制

游戏每 **30 秒**执行一次 Tick（游戏内约 1 小时），自动结算：
- 所有业务的收益与成本
- 员工薪资扣除与疲劳变化
- 压力自然衰减
- 忠诚度与声誉衰减
- 维护成本扣除
- 供应链状态更新
- 竞争对手市场份额变化
- 贷款利息扣除
- 子公司自动运营
- 经济周期波动
- 资产市场价格更新与拍卖结算
- LLM 商业新闻/情报/情绪/动态事件生成

### 时间系统

游戏内 24 个 Tick = 1 个游戏日。支持黎明/白天/黄昏/夜晚四个时段，影响业务收益。

### 天气系统

游戏包含 7 种天气类型，影响业务收入和事件触发：

| 天气 | 收入影响 | 事件倾向 |
|------|----------|----------|
| ☀️ 晴天 | 100% | 中性 |
| ☁️ 多云 | 100% | 中性 |
| 🌧️ 雨天 | 95% | 偏负面 |
| ⛈️ 暴风雨 | 85% | 危机 |
| 🌫️ 雾天 | 90% | 中性 |
| ❄️ 雪天 | 88% | 中性 |
| 🔥 高温 | 92% | 偏负面 |

### 季节与节日系统

游戏模拟一年 360 天四季轮回，包含 12 个节日（春节、元宵、清明、劳动、端午、七夕、中秋、国庆、双十一、双十二、元旦、圣诞），节日期间相关业务获得临时收益加成。

### 玩家属性

| 属性 | 说明 |
|------|------|
| 💰 资产 | 当前现金，低于 -50万 连续 8 个 Tick 将触发破产 |
| ⭐ 声誉 | 0-100，影响区域解锁、NPC关系和贷款利率 |
| 😰 压力 | 0-100，过高影响决策质量，积累触发负面事件 |
| 🤝 人脉 | 上限 100，社会关系网络值，影响合作机会 |
| 📊 市场情绪 | 0-100，LLM 分析输出，影响股价和事件触发 |

### 手动工作

点击中央区域的**手动拉项目**按钮（或按 `空格`）可立即获得一次性收益，但有 **20 Tick 冷却时间**，且有 8% 概率触发负面结果。25% 概率额外获得 1-2 人脉。

## 业务系统

### 业务类型

| 业务 | 图标 | 解锁条件 | 特点 |
|------|------|----------|------|
| 便利连锁 | 🏪 | 初始 | 稳定现金流，低风险 |
| 餐饮连锁 | 🍽️ | 50万 | 每级增加1个员工槽 |
| 科技工作室 | 💻 | 150万+第1幕 | 高收益，需研发点 |
| 写字楼租赁 | 🏢 | 300万+第2幕 | 被动收入，稳定 |
| 量化基金 | 📈 | 1000万+第2幕 | 超高收益，高风险 |
| 新能源开发 | ⚡ | 800万+第3幕 | 3级以上有政府补贴 |
| 媒体矩阵 | 📺 | 3000万+第3幕 | 高收益，声誉加速 |

### 升级系统

每个业务有 **10 个等级**，升级需满足：
1. 业务所在区域必须已解锁
2. 资金充足
3. 达到对应幕次要求
4. **满足前置条件（reqCond）**：部分高等级需要特定科技等级、NPC好感度或声誉

> 💡 不满足前置条件时，升级按钮会显示提示（如"需科技Lv2"、"需林教授好感40"）

### 维护成本

每 Tick 产生维护成本 = 业务收入 × 基础比例(2%) + 等级附加(0.5%/级)。业务等级越高，维护成本占比越大。

### 业务协同

同一区域或类型的多条业务线可产生**协同加成**，中央区域顶部会显示当前协同状态。

## 员工管理

### 员工上限

初始员工上限为 **5人**，通过以下方式扩展：
- 餐饮连锁每升一级 +1
- 每个产业 +1，每个已解锁区域 +1
- 技能树「矩阵管理」+3
- 特定事件奖励

### 员工角色

| 角色 | 薪资(万/Tick) | 效果 | 解锁条件 |
|------|---------------|------|----------|
| 🎓 实习生 | 0.3 | 基础劳动力 | 无 |
| 💻 开发者 | 1.5 | 科技业务 +15% | 有科技工作室 |
| 🎨 设计师 | 1.2 | 媒体/零售 +10% | 无 |
| 🤝 销售 | 1.0 | 零售 +20%，人脉 +2/月 | 无 |
| 📊 分析师 | 1.3 | 负面事件 -3%/人 | 无 |
| 📋 管理者 | 2.0 | 业务 +30%，忠诚衰减 -50% | 员工数≥5 |
| ⚖️ 律师 | 1.8 | 监管伤害 -50% | 资产500万+ |
| 👥 HR | 1.2 | 忠诚衰减 -50%，招聘成本 -20% | 无 |
| 💰 财务 | 1.4 | 税务优化 +5%，资金周转 +10% | 无 |
| 📣 市场 | 1.1 | 声誉 +15%，产品发布 +20% | 无 |
| ♟ CTO | 3.0 | 全局科技 +20% | 科技5级+员工≥8 |

### 员工深度系统

- **疲劳度**：员工每 Tick 积累疲劳，疲劳过高影响效率和忠诚度，自然恢复
- **培训系统**：花费资金培训员工技能，最高 5 级
- **忠诚度**：随时间自然衰减，过低可能**主动离职**
- **Burnout**：长期加班触发过度劳累事件
- 解雇员工需支付赔偿
- **LLM 生成员工背景**：招聘时 AI 自动生成个性化员工故事

### HR 统管模式

当员工数超过阈值（无 HR 时 8 人，有 HR 时 5 人），自动进入 HR 统管模式：
- 批量招聘（成本折扣 20%）、批量培训（成本折扣 30%）
- 工资折扣 5%
- 每 Tick 自动降低全员工疲劳值

## 资产购置与拍卖行

> **全新系统**：将闲置资金投入实体资产，在需要时通过拍卖行挂牌出售或紧急典当变现。价格随市场情绪波动涨跌。

### 资产类型（5 类 26 种）

| 类别 | 数量 | 典型物品 | 特点 |
|------|------|----------|------|
| 🏠 房产 | 6 种 | 市中心公寓、写字楼整层、顶层复式 | 波动低、稳定升值 |
| 🎨 艺术品 | 6 种 | 名家水墨、数字藏品、油画巨作 | 波动高、偶尔暴涨 |
| 💍 珠宝 | 5 种 | 钻戒、翡翠手镯、传世皇冠 | 中等波动、保值 |
| 🏺 古董 | 5 种 | 青花瓷瓶、青铜器、紫檀家具 | 慢速稳定增值 |
| 📜 股权 | 4 种 | 创业公司股权、矿产开采权 | 极高波动、高风险回报 |

### 稀有度

| 稀有度 | 标签色 | 特点 |
|--------|--------|------|
| 普通 | 灰色 | 价格低，波动温和 |
| 稀有 | 绿色 | 中等价位，有一定升值空间 |
| 珍品 | 蓝色 | 高价，趋势良好 |
| 史诗 | 紫色 | 极高价，长线升值潜力巨大 |

### 价格机制

- **市场价** = 基准价 × 情绪因子(0.7~1.3) × 随机浮动(0.85~1.15)
- **持有市值** 随 Tick 波动：趋势漂移 + 随机波动 + 市场情绪影响
- **下限保护**：市值不会低于购买价的 20%

### 操作入口

| 操作 | 触发方式 | 说明 |
|------|----------|------|
| 浏览市场 | 面板 `💎 资产` 或按 `8` | 8 件随机资产，每 12 Tick 刷新 |
| 购买资产 | 市场卡片点击「购买」 | 资金充足 + 槽位未满（上限 20） |
| 挂牌拍卖 | 我的资产点击「🔨 挂牌」 | 自定义要价，3-8 Tick 自动成交 |
| 取消拍卖 | 拍卖行中点击「取消」 | 撤回挂牌 |
| 紧急典当 | 我的资产点击「💸 典当」 | 即时回款，38%-55% 市值 |
| 仪表盘 | `💎 资产估值` 卡片 | 总市值 + 持有数量 |

### 拍卖机制

- 挂牌后可自定义要价，系统根据市场价评估成交概率
- 要价越接近市场价，成交概率越高（最高 95%）
- 偏离越大，成交概率越低（最低 15%）
- 未成交时自动延长等待并微调降价
- 成交后资金即时到账

### 托管集成

- **资金充裕时**（保留 30% 流动储备）：自动选购高趋势/低波动资产
- **资金窘迫时**（低于 2 倍单 Tick 支出）：自动典当市值最低的非拍卖资产救急

- 支持**离线收益**：关闭游戏后重新打开，系统会计算最多 **24小时** 的离线收益
- 支持**存档导入/导出**，可用于迁移或备份
- 删除 `saves/` 文件夹内的 JSON 文件即可清除对应存档

> ⚠️ 存档只存在服务器本地，删除 `saves/` 里的文件即永久删除，请谨慎操作。

## 常见问题

**Q：LLM 离线了，游戏还能玩吗？**
A：可以正常游玩所有核心功能。事件叙事、NPC对话等使用预设模板代替，商业新闻/竞争情报/市场情绪/动态事件等 LLM 增强功能暂停。

**Q：游戏卡顿了怎么办？**
A：减少同时运行的业务数量，或关闭不必要的面板。

**Q：为什么资产一直减少？**
A：检查员工总薪资、业务运营成本和维护成本是否超过了收益。也可考虑典当部分资产救急（按 `8` 进入资产面板）。

**Q：业务升级按钮为什么是灰色的？**
A：升级需要满足前置条件（reqCond），鼠标悬停在按钮上可查看具体要求（如科技等级、NPC好感、声誉等）。

**Q：如何触发 LLM 生成的特殊事件？**
A：保持 LLM 在线状态，随机事件触发时（约每 **6 Tick** 检查一次，基础概率 **25%**）会调用 LLM 生成叙事。每 **25 Tick** 有 30% 概率触发完全由 LLM 即时生成的动态事件。

**Q：存档在哪里，如何备份？**
A：存档在游戏目录下的 `saves/` 文件夹，直接复制 JSON 文件即可备份。也可通过设置面板的导入/导出功能迁移存档。

**Q：游戏时间和现实时间的关系？**
A：每 **30 秒**现实时间 = 游戏内约 1 小时；每 24 个 Tick = 1 个游戏日。

**Q：托管模式为什么没触发？**
A：请确认在设置面板中勾选了「🔛 启用全自动托管（主开关）」。仅勾选子策略开关不会自动启用托管。

**Q：为什么收入比预期少？**
A：可能原因：竞争对手抢占市场份额、供应链断裂、经济周期处于萧条/危机、维护成本扣除。检查市场份额和供应链状态。

**Q：子公司是什么？**
A：解锁多个城市后，可将非当前城市转为子公司自动运营，获得 60%-80% 的收益分成，无需手动管理。

**Q：天气和节日影响游戏吗？**
A：会。不同天气影响业务收入（-5% ~ -15%），节日期间相关行业有额外加成（+10% ~ +40%）。经济周期也会显著影响全局收益。

**Q：资产如何买卖？**
A：按 `8` 进入资产中心。市场每 12 Tick 刷新 8 件随机资产，可直接购买。已购资产可挂牌拍卖（自定义要价，3-8 Tick 自动成交）或紧急典当（即时回款 38%-55% 市值）。

**Q：市场情绪是什么？**
A：LLM 每 15 Tick 分析游戏全局状态输出的 0-100 指数，影响股价波动、资产价格、事件触发概率。仪表盘实时展示。

**Q：资产价格为什么会波动？**
A：资产持有市值受三方面影响：市场情绪起伏、趋势漂移（长期升值/贬值）、随机波动。极品资产（史诗级）通常长线升值，而数字藏品等高波动品类短期波动剧烈。

**Q：典当和拍卖有什么区别？**
A：拍卖需要等待 3-8 Tick，有机会以接近市场价甚至更高价卖出；典当即时回款，但只能拿到市场价的 38%-55%（相当于割肉救急）。
