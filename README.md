# 商海浮沉 — 使用说明

> LLM 驱动的放置式经营模拟游戏。在虚构的商业都市里，从一无所有到商业帝国，每一步都由你决策。

## About

A browser-based idle business simulation game powered by local LLM (Ollama). Start from nothing — choose your origin, build businesses across cities, manage employees, negotiate with NPCs, trade stocks, and climb your way to a commercial empire. Every decision matters, and the LLM generates dynamic narratives for key events.

**Tech Stack:** Vanilla JS + Ollama API
**Play:** 运行 `启动游戏.bat` 或 `python server.py`，浏览器访问 `http://localhost:8765`

## 快速开始

### 方式一：通过 .bat 文件启动（推荐）

双击 **`启动游戏.bat`**，游戏将自动在浏览器中打开。

### 方式二：手动启动本地服务器

> ⚠️ **必须通过 HTTP 服务器打开**，直接双击 `index.html` 会导致 LLM 功能因浏览器安全限制而无法使用。

```bash
# 在游戏目录打开终端，运行：
python server.py

# 然后在浏览器中访问：
http://localhost:8765
```

### 关闭游戏

双击 **`关闭游戏.bat`**，或在游戏内点击顶栏的 **🚪 退出游戏** 按钮。

## LLM 配置

游戏深度集成本地 LLM，用于生成**事件叙事、NPC 对话、员工背景故事、决策描述**等内容。没有 LLM 时游戏仍可正常进行，但叙事体验会大幅减弱。

### 默认配置

| 参数 | 默认值 |
|------|--------|
| LLM 接口地址 | `http://localhost:11434`（Ollama） |
| 模型 | `qwen3.5:4b` |
| Temperature | 0.7 |
| 最大 Token | 300 |

### 配置步骤

1. 确保已安装并运行 [Ollama](https://ollama.com/)
2. 拉取推荐模型：`ollama pull qwen3.5:4b`
3. 游戏内点击顶栏 **⚙ 设置** → 修改接口地址和模型名称
4. 顶栏左侧绿色圆点亮起表示 LLM 已连接

### LLM 功能开关

在设置面板中可以分别开启/关闭：
- **事件叙事**：随机事件的 AI 描述
- **员工背景**：招聘时生成员工故事
- **NPC 对话**：人脉 NPC 的 AI 台词
- **决策叙事**：重大决策的背景描述

## 核心玩法

### 放置机制

游戏每 **30 秒**执行一次 Tick（游戏内约 1 小时），自动结算：
- 所有业务的收益与成本
- 员工薪资扣除与疲劳变化
- 压力自然衰减
- 忠诚度与声誉衰减
- 维护成本扣除
- 供应链状态更新
- 竞争对手市场份额变化
- 贷款利息扣除

### 时间系统

游戏内 24 个 Tick = 1 个游戏日。

### 玩家属性

| 属性 | 说明 |
|------|------|
| 💰 资产 | 当前现金，低于 -50万 连续8个Tick将触发破产 |
| ⭐ 声誉 | 0-100，影响区域解锁、NPC关系和贷款利率 |
| 😰 压力 | 0-100，过高影响决策质量，积累触发负面事件 |
| 🤝 人脉 | 社会关系网络值，影响合作机会 |

### 手动工作

点击中央区域的**手动拉项目**按钮（或按 `空格`）可立即获得一次性收益，但有 **20 Tick 冷却时间**，且有 8% 概率触发负面结果。

## 业务系统

### 业务类型

| 业务 | 图标 | 解锁条件 | 特点 |
|------|------|----------|------|
| 便利连锁 | 🏪 | 初始 | 稳定现金流，低风险 |
| 餐饮连锁 | 🍽️ | 50万 | 每级增加1个员工槽 |
| 科技工作室 | 💻 | 150万+第1幕 | 高收益，需研发点 |
| 写字楼租赁 | 🏢 | 300万+第2幕 | 被动收入，稳定 |
| 量化基金 | 📈 | 1000万+第2幕 | 超高收益，高风险 |
| 新能源开发 | ⚡ | 800万+第3幕 | 3级以上有政府补贴 |
| 媒体矩阵 | 📺 | 3000万+第3幕 | 高收益，声誉加速 |

### 升级系统

每个业务有 **10 个等级**，升级需满足：
1. 业务所在区域必须已解锁
2. 资金充足
3. 达到对应幕次要求
4. **满足前置条件（reqCond）**：部分高等级需要特定科技等级、NPC好感度或声誉

> 💡 不满足前置条件时，升级按钮会显示提示（如"需科技Lv2"、"需林教授好感40"）

### 维护成本

每 Tick 产生维护成本 = 业务收入 × 基础比例(2%) + 等级附加(0.5%/级)。业务等级越高，维护成本占比越大。

### 业务协同

同一区域或类型的多条业务线可产生**协同加成**，中央区域顶部会显示当前协同状态。

## 员工管理

### 员工上限

初始员工上限为 **5人**，通过以下方式扩展：
- 餐饮连锁每升一级 +1
- 技能树「矩阵管理」+3
- 特定事件奖励

### 员工角色

| 角色 | 薪资(万/Tick) | 效果 | 解锁条件 |
|------|---------------|------|----------|
| 🎓 实习生 | 0.3 | 基础劳动力 | 无 |
| 💻 开发者 | 1.5 | 科技业务 +15% | 有科技工作室 |
| 🎨 设计师 | 1.2 | 媒体/零售 +10% | 无 |
| 🤝 销售 | 1.0 | 零售 +20%，人脉 +2/月 | 无 |
| 📊 分析师 | 1.3 | 负面事件 -3%/人 | 无 |
| 📋 管理者 | 2.0 | 业务 +30%，忠诚衰减 -50% | 员工数≥5 |
| ⚖️ 律师 | 1.8 | 监管伤害 -50% | 资产500万+ |
| 👥 HR | 1.2 | 忠诚衰减 -50%，招聘成本 -20% | 无 |
| 💰 财务 | 1.4 | 税务优化 +5%，资金周转 +10% | 无 |
| 📣 市场 | 1.1 | 声誉 +15%，产品发布 +20% | 无 |
| ♟ CTO | 3.0 | 全局科技 +20% | 科技5级+员工≥8 |

### 员工深度系统

- **疲劳度**：员工每 Tick 积累疲劳（0.3/Tick），疲劳过高影响效率，自然恢复（0.5/Tick）
- **培训系统**：花费资金培训员工技能，最高 5 级
- **忠诚度**：随时间自然衰减，过低可能**主动离职**
- **Burnout**：长期加班触发过度劳累事件
- 解雇员工需支付赔偿

## 存档说明

- 游戏每 **8 Tick** 自动保存一次
- 存档**仅保存在服务器端 `saves/` 文件夹**（JSON 文件）
- 支持**多槽位存档**（slot 1/2/3），可在设置中管理
- 支持**离线收益**：关闭游戏后重新打开，系统会计算最多 **24小时** 的离线收益
- 删除 `saves/` 文件夹内的 JSON 文件即可清除对应存档

> ⚠️ 存档只存在服务器本地，删除 `saves/` 里的文件即永久删除，请谨慎操作。

## 常见问题

**Q：LLM 离线了，游戏还能玩吗？**
A：可以正常游玩所有核心功能，只是事件叙事、NPC对话等文字内容会使用预设模板代替。

**Q：游戏卡顿了怎么办？**
A：减少同时运行的业务数量，或关闭不必要的面板。

**Q：为什么资产一直减少？**
A：检查员工总薪资、业务运营成本和维护成本是否超过了收益。临时解雇部分员工或暂停高成本业务。

**Q：业务升级按钮为什么是灰色的？**
A：升级需要满足前置条件（reqCond），鼠标悬停在按钮上可查看具体要求（如科技等级、NPC好感、声誉等）。

**Q：如何触发 LLM 生成的特殊事件？**
A：保持 LLM 在线状态，随机事件触发时（约每 **6 个 Tick** 检查一次，基础概率 **25%**）会调用 LLM 生成叙事。

**Q：存档在哪里，如何备份？**
A：存档在游戏目录下的 `saves/` 文件夹，直接复制 JSON 文件即可备份。

**Q：游戏时间和现实时间的关系？**
A：每 **30 秒**现实时间 = 游戏内约 1 小时；每 24 个 Tick = 1 个游戏日。

**Q：托管模式会自动拉项目吗？**
A：会。开启托管后，每3个Tick检查一次手动拉项目的冷却，冷却结束即自动执行。

**Q：为什么收入比预期少？**
A：可能原因：竞争对手抢占市场份额、供应链断裂、维护成本扣除。检查市场份额和供应链状态。

**Q：为什么 `data.js` 里的事件描述报错？**
A：已修复。`data.js` 中的事件 `getDesc` 函数现已正确使用 `SGame.G` 而非 `G`，不会再出现 `G is not defined` 错误。
